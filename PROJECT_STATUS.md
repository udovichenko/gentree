# GenTree - Приложение для визуализации генеалогического дерева

## Общее описание

GenTree - это веб-приложение для визуализации семейного дерева, построенное на React + TypeScript с использованием Vite. Приложение позволяет импортировать данные из GEDCOM-файлов и отображать генеалогическое дерево с интерактивным интерфейсом.

## Технологический стек

- **Frontend Framework**: React 18 + TypeScript
- **Build Tool**: Vite 7
- **Визуализация дерева**: React Flow (для узлов и интерактивности) + собственный SVG-слой (для линий связей)
- **UI Framework**: Ant Design 5
- **Хранение данных**: Dexie.js (IndexedDB)
- **Стилизация**: SCSS Modules
- **Парсинг GEDCOM**: Кастомный парсер

## Особенности реализации

### Почему не используются edges React Flow?
React Flow связывает edges только между узлами (node-to-node). Для генеалогического дерева нужны линии от середины связи супругов к детям, что невозможно с стандартными edges. Поэтому линии рисуются отдельным SVG-слоем с правильными координатами.

### Алгоритм раскладки
Используется рекурсивный алгоритм:
1. Начинаем с корневой персоны
2. Размещаем предков вверх (рекурсивно)
3. Размещаем потомков вниз (рекурсивно)
4. При размещении проверяем коллизии с уже размещёнными узлами
5. Ищем свободное место при обнаружении коллизии

### Фиксация Y-координаты
Y-координата узла определяется поколением и фиксирована. При перетаскивании узла меняется только X, что сохраняет структуру поколений.
